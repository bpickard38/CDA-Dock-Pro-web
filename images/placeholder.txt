CDA DOCK PRO — Image Placeholder Guide
=======================================

Replace the CSS gradient placeholders in index.html and dock-pro.css
with real photos once you have them. Each slot is marked with a comment
in the source file.

IMAGES NEEDED
-------------

1. Hero Background
   File name:   images/hero.jpg  (or hero.webp)
   Dimensions:  1920 × 1080 px minimum
   Content:     Wide lakeside shot — a clean dock on Coeur d'Alene or Hayden
                with the water and mountains in the background. Golden-hour
                lighting works great with the navy overlay.
   Where to add: styles/dock-pro.css → .section-hero rule
                 Add: background-image: url(../images/hero.jpg);

2. Before Photo (Comparison Slider)
   File name:   images/before.jpg
   Dimensions:  800 × 450 px
   Content:     Dirty dock — algae, mildew stains, bird droppings, cobwebs.
                The grimier the better for contrast.
   Where to add: index.html → .slider-panel--before div
                 Add: <img src="images/before.jpg" alt="Dock before pressure washing">
                 OR in CSS: background-image: url(../images/before.jpg);

3. After Photo (Comparison Slider)
   File name:   images/after.jpg
   Dimensions:  800 × 450 px  (same crop/angle as before.jpg for best effect)
   Content:     Same dock, freshly cleaned. Bright, wet boards, crisp lines.
   Where to add: index.html → .slider-panel--after div

4. Service Card — Deep Pressure Wash
   File name:   images/pressure-wash.jpg
   Dimensions:  600 × 400 px
   Content:     Action shot — pressure washer wand on dock boards, spray visible.
   Where to add: index.html → .card-image--wash div
                 Add: background-image: url(images/pressure-wash.jpg);

5. Service Card — Restoration & Sealing
   File name:   images/restoration.jpg
   Dimensions:  600 × 400 px
   Content:     Close-up of freshly stained/sealed natural wood boards, rich grain.
   Where to add: index.html → .card-image--restore div

6. Service Card — Seasonal Maintenance
   File name:   images/maintenance.jpg
   Dimensions:  600 × 400 px
   Content:     Dock in late fall or spring — seasonal context, ideally with
                the lake visible.
   Where to add: index.html → .card-image--maintain div

IMAGE TIPS
----------
- Shoot in RAW if possible, export as JPEG (quality 80%) or WebP (quality 75%)
- WebP is preferred — roughly 30% smaller file size than JPEG
- Compress with squoosh.app (free, browser-based) before deploying
- Add alt text to all <img> tags for accessibility and SEO
- The before/after images should be taken from the same angle/position
  for the slider effect to be visually impactful
- For the hero, make sure the focal point is centered or upper-center
  (the headline overlays the lower-middle)

SEO NOTE
--------
Name image files descriptively:
  Good: coeur-dalene-dock-pressure-washing-before.jpg
  Bad:  IMG_4821.jpg

Google image search is a free lead source for local service businesses.
